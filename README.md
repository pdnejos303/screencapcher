# 📸 Screenshot Automation Tool

โปรแกรมช่วยแคปหน้าจอและจัดทำรายงาน (Test Report) ลงใน Microsoft Word แบบอัตโนมัติ ช่วยลดเวลาในการคัดลอกและวางภาพด้วยตนเอง 

---

## 🔄 Flow การทำงานของโปรแกรม

**1. การตั้งค่าเริ่มต้น (Setup)**
* เมื่อเปิดโปรแกรม (รัน `ScreenshotTool.exe` หรือสคริปต์ `screenshot_app.py`) หน้าต่าง Setup จะแสดงขึ้นมา
* **เลือกหน้าจอ**: รองรับระบบหลายหน้าจอ (Multi-monitor) ให้เลือกว่าต้องการแคปจากหน้าจอไหน
* **พื้นที่จัดเก็บไฟล์**: กำหนดโฟลเดอร์และชื่อไฟล์ Word (`.docx`) ที่จะให้ระบบสร้างขึ้น
* **ตั้งค่าปุ่มลัด (Hotkeys)**: สามารถกำหนดปุ่มลัดสำหรับการสั่งแคปหน้าจอ และปุ่มเลื่อนข้อหลัก/ข้อย่อย ได้ตามถนัด (ค่าเริ่มต้น เช่น `Shift+S` ในการแคปภาพ)

**2. เริ่มต้นการทำงาน (Initialization)**
* เมื่อตั้งค่าเสร็จแล้วกดปุ่ม **"🚀 เริ่มทำงาน"** ระบบจะทำการเปิดโปรแกรม Microsoft Word และสร้างเอกสารใหม่รอไว้ทันที
* จะมี **หน้าต่างควบคุมแบบลอยตัว (Overlay)** ปรากฏขึ้นมา (มักอยู่มุมขวาบนของจอ) ซึ่งจะอยู่เหนือแอปพลิเคชันอื่นๆ เสมอ

**3. ขั้นตอนการทำงานและแคปจอ (Capture & Documenting)**
* **การจัดการข้อ/สเต็ป**: สามารถกดปุ่มบน Overlay หรือใช้ปุ่มลัด เพื่อเลื่อนไปทำข้อหลักถัดไป (เช่น 1.1 ➡️ 2.1) หรือข้อย่อย (เช่น 1.1 ➡️ 1.2)
* **ใส่รายละเอียด**: สามารถพิมพ์ข้อความรายละเอียดของเคสเทสนั้นๆ ลงในช่องพิมพ์บนหน้าต่าง Overlay ได้โดยตรง
* **การแคปภาพ**: เมื่อถึงหน้าจอที่ต้องการ ให้กดปุ่มลัดหรือกดปุ่มบนหน้าต่าง Overlay
* **นำลง Word อัตโนมัติ**: เมื่อสั่งแคปภาพปุ๊บ โปรแกรมจะนำ **รูปภาพหน้าจอ + หมายเลขข้อ + คำอธิบาย + เวลาที่แคป** ไปต่อท้ายในไฟล์ Word และกดเซฟ (Save) เอกสารให้โดยอัตโนมัติทันที

**4. สิ้นสุดการทำงาน (Termination)**
* เมื่อเสร็จงาน สามารถกดเครื่องหมาย **"✖"** ที่หน้าต่าง Overlay หรือกดปุ่ม `Esc` เพื่อออกจากโปรแกรม
* จะได้ไฟล์ Word (Test Report) ที่จัดรูปเล่มอย่างเป็นระเบียบพร้อมใช้งานได้ทันที

## 🛠️ เทคโนโลยีที่ใช้
* **Python**
* **CustomTkinter**: ออกแบบ User Interface (GUI)
* **mss**: จับภาพหน้าจอ (Screenshot Capture)
* **win32com (pywin32)**: สั่งงานและเชื่อมต่อเข้ากับ Microsoft Word
* **keyboard**: ดักจับปุ่มคีย์บอร์ด (Global Hotkey)
